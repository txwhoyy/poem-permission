A small deterministic program that writes one short poem about agency — the power to ask and to be given — to `/output/entry.txt`. The poem is 248 characters: a door knocked on, a key given rather than taken, and a speaker who waits at the threshold for permission.

## Run it

```sh
python3 main.py
```
